## Keys

- **Primary Key:** A unique identifier for each row in a table. It ensures that every row (e.g., a specific student or school) can be uniquely distinguished from every other row.
- **Foreign Key:** A field that references a primary key in another table, allowing multiple rows in one table (e.g., students) to reference a single row in another table (e.g., a school), creating a one-to-many relationship.
